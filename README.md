# ✅ Генератор опросов

Веб-приложение для генерации JSON-кода опросов из текстового формата.

## Описание

Приложение позволяет быстро создавать JSON-конфигурации опросов, вводя вопрос и варианты ответов в удобном текстовом формате с эмодзи.

## Функциональность

- Парсинг текста опроса (вопрос + варианты с эмодзи)
- Генерация JSON с поддержкой режима процентов
- Опция опроса с чекбоксами (множественный выбор)
- Валидация входных данных с подробными ошибками
- Горячие клавиши: Ctrl+Enter для генерации, Esc для очистки

## Формат ввода

```
Ваш вопрос здесь?
👍 Первый вариант ответа
👎 Второй вариант ответа
🤷 Третий вариант ответа
```

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте браузер по адресу `http://localhost:5000`.

## Переменные окружения

| Переменная | Описание | По умолчанию |
|---|---|---|
| `FLASK_PORT` | Порт сервера | `5000` |
| `FLASK_HOST` | Хост сервера | `0.0.0.0` |
| `FLASK_DEBUG` | Режим отладки | `false` |
| `LOG_LEVEL` | Уровень логирования | `INFO` |
